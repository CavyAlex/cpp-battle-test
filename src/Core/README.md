`Core` — это расширяемая основа проекта. 

## Что лежит в Core
- `World` — состояние мира и единственное место его изменения: `spawn`, `march`, `moveTo`, `changeHp`. Каждое изменение пишет событие в лог.
- `Unit` — базовый класс: id, тип, позиция, HP, движение, занятость клетки, `act()` и `incomingAttackRange()`.
- `Simulation` — ходы в порядке создания юнитов, уборка погибших, условие окончания.
- `Pathfinding` — выбор следующей клетки на пути к цели.

## Правила для изменений Core
- Сюда попадает только то, что нужно многим юнитам и должно соблюдаться всегда. Поведение конкретного юнита живёт в Features.
- Новый примитив изменения состояния добавляется, только если без него юнит из Features не может обойтись.
- Любое изменение Core проверяется полным прогоном тестов: `cmake --build build && ctest --test-dir build`.
